What does not change between themes. Emerald #10B981 and its hover colours; the six category colours (Traffic blue, Pages violet, Offers orange, Actions teal, Logic amber, Goals lime); the leak orange; layout, spacing, type sizes and fonts; every object, port, line style and icon shape. Text on the Emerald button stays dark green (6.5 : 1 in both). Only surfaces, borders and text colours swap, and the accent text colours are darkened in Light so they stay readable on white.
Dark stays exactly as it is. Every dark board in this file is unchanged; Light is added beside it as a separate set of values. Dark is the default for everyone, and new people start in Dark.
Known item in Dark (left alone, as requested). Muted tertiary text in Dark measures 3.9 : 1, a little under the 4.5 : 1 target. Light passes everywhere. If you ever want it raised, it is a one-token change.
Never colour alone. The rule applies in both themes: leaks stay dashed, checks stay worded, and every status keeps its shape or label.
