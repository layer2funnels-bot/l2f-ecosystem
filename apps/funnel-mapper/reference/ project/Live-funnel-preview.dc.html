Live funnel preview

Every funnel card shows its own map, drawn from the funnel’s saved canvas by the same code that draws it in the editor. It is not a template thumbnail and not a screenshot, so it cannot go stale.

What changed.
V1 shows a decorative shape that is the same on almost every card, and the text “Empty map” on two of them. It is not connected to the funnel, so it cannot be right for long.

V2 reads the funnel’s saved canvas and draws it: every block as a small version of its real object (a page shows its window and caption bar, an offer its price tab, sources, messages and logic their own shapes), every connection, the dashed orange leak path, frames, and line thickness by people. Change the map, and the card changes with it. No image is stored, so it can never be stale.

5 · Rules
RuleSpec
Source of truthThe funnel’s saved canvas (blocks, connections, frames). Not an image, not a copy. If the map is saved, the preview can be re-drawn from it.
When it updatesOn every save of the map, and when a list is opened. A card is never more than one save behind. Other people’s changes appear on the next list load.
What it drawsEvery block as a miniature of its real object; every connection; flow in slate, leaks dashed orange, skips dotted; thickness by people (square root, 1–3px); frames. The block that leaks most carries a dashed orange ring: the same fact as Biggest leak in the funnel panel.
What it ignoresNotes, text and images. They never change the scale. A note inside the fitted area is drawn at 55%.
FitPadding 8px (4px in tables). Scale = min(width/bbox, height/bbox, 0.5). Centred. Same rule at every size.
Detail by sizeScale 0.30 and above: names. 0.11 and above: window, caption bar, price tab. Below 0.11: family-coloured shapes with a white window on pages and offers.
Limits60 blocks or fewer: full detail. 61–200: shapes only. More than 200: blocks without connections, and the card says so.
ClickThe whole card opens the map. Reports and the status menu stay separate controls with their own targets.
AccessibilityText alternative: “Map of {name}: 8 blocks, 7 connections”. Orange ring is paired with the dashed line and the Biggest leak text, never colour alone.
PermissionsViewers and share links see the same preview. A share link can hide numbers; the preview has none.
Future Visual BrainA page’s window already holds its screenshot, so later analysis can attach to the page object with no layout change. Nothing is added to the preview now.
