Each type keeps its own window — never a generic placeholder.

Where the thumbnail travels: the captured image fills the object's page window at every zoom on the canvas, on the selected object, in the library's recents, in Presentation and in PDF / PNG / SVG exports.  ·  The fallback is the design, not a stopgap: with no URL the window shows the semantic wireframe for its page type, so a map is fully readable before any page exists.  ·  Capture is display-only — it never touches funnel maths or the data model.
