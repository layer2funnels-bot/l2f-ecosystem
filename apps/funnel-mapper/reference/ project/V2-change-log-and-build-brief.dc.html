Build brief for Claude Code

Templates inside the map (#4) and the form (#2)
New feature. This does not exist in the app yet. Add a TEMPLATES array with the 13 templates exactly as on the Template structures artboard (names, order, nodes, lines, dashed paths). Add insertTemplate(id, options) that places the group at the center of the current view inside a labelled frame and never moves existing blocks. Add a modal that returns the funnel name and a name and URL per page; all fields optional. The same form opens from the Templates page and from the map.
Month-to-month data and calendar (#5)
New feature. This does not exist in the app yet. Add a funnel_actuals table: funnel_id, node_id, period_type (month or week), period_start, visitors, conversions, revenue, spend. Add a date-range picker (presets Today, This month, Last 30 days, Custom range) and a Model / Actual toggle. In Actual mode the map shows summed actuals for the chosen dates. Add the data-entry grid with Monthly and Weekly views, paste from sheet and CSV import. Reuse lib/funnel-math.ts for every derived number.
URL import and image limit (#8)
New feature. This does not exist in the app yet. A server route takes a page URL and returns a screenshot thumbnail; block private IP ranges and localhost, add a timeout and a rate limit. Compress every image to under 100 KB before it is stored: resize, convert to WebP, lower quality step by step. If it still will not fit, reject it with a plain message and store nothing. This covers thumbnails, screenshots, logos and custom icons. No image above 100 KB may exist anywhere.
Home date range (#9)
New feature. This does not exist in the app yet. Build one shared range picker (presets, from and to month and year, month grid) used by Home and the editor. Dashboard totals aggregate by the chosen range. Show planned revenue and MRR as one row per currency, never added together.
Trash and delete confirmation (#12, #13)
New feature. This does not exist in the app yet. Soft delete with a deleted_at column on clients and funnels. Deleting a client soft-deletes its funnels in the same action. Add the Trash page with Restore, Delete forever and Empty trash, plus a scheduled job that removes items after 30 days. Funnel delete uses a plain confirm; client delete asks for the typed name.
Smaller changes
Right panel collapse with the ] key and left with [ (state remembered per user). Four ports per block with line types chosen on the line. Block count read from the block list length, never typed. Page thumbnail preview listens on the thumbnail element only. Plain-language edge labels and a formula line under every number in the inspector.
