Page & offer objects

The page object is a funnel object, not a card: a browser window of the page, its name and numbers, and a dark type caption. Four plain ports let a block connect on any side; the line says whether people continue or leave. Every page and offer in the library uses this one object, at one size.

  1. Page window A semantic wireframe of the page type, or the real screenshot once a URL is captured. Always portrait, always 68×76.
  2. Name What the strategist calls this step. Two lines maximum, then truncates.
  3. Flow and result People in → people through, then the headline number (conversion for pages, revenue for offers).
  4. Type caption Dark strip that names the page type in category colour, with a status dot (live / planned). Readable without the window.
  5. Ports Four plain ports: top, right, bottom, left. What a line means (Yes, No, Skip step, No data) is chosen when you connect.

Rules. Width 196, height 112 (pages and offers are 38px taller than other families, so rows stay centre-aligned and lines stay straight). Window 68×76, 8px left / 7px top, 10px gap to the text column. Caption bar 22px. Port 16px. Offers add a 20px price tab at −10px. Numbers use Bricolage Grotesque; all other text DM Sans. Previews are display-only and never touch the funnel maths.
