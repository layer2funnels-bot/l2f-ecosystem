5 · What happens to the old box style settings
Style settings to remove
Box border (colour, width, style)
There is no box.
Corner radius
Radius is fixed by the design.
Box fill / background
The picture is the block.
Font weight, size, alignment
One type scale; the name is always under the block.
Compact / expanded card
One block size; zoom changes the detail.
Caption bar, status dot, in/out text line
Replaced by the single number chip and the type glyph.
Style settings to keep
Accent colour
Optional override of the family colour (bottom bar, glyph, disc).
Icon

Show or hide the number chip
Per block.
Name

Footer of the settings box.
Never messy. Per block: one picture, one name, one number chip, one type glyph. Nothing else is drawn at rest. Ports, the preview and the warning mark appear only when needed.
Names are protected. Two lines at most, then an ellipsis; the full name is in the tooltip and the settings box. Names never overlap neighbours: spacing is 240px across and 200px down.
Zoom decides detail. Far: shapes and lines only. Mid: names. Near: number chips and subtype.
