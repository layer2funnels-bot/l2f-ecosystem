Status is gone from blocks. A funnel has a status (Draft or Live). Blocks do not need one: nobody should set it block by block. If you want build progress, it is an optional layer: select several blocks and set them together.
No fractions. “0.1 avg” and “0.5 avg” are gone. Whole people; <1 for tiny values.
Cost leaves the step table. Cost belongs to sources and offers (their Settings and Pricing tabs), not to every step.
One home per number. The funnel panel no longer repeats revenue, spend and profit; the strip has them. Details is inputs only; Analytics is results only.
The dates follow the calendar. The panel says which dates it shows, and changes with the calendar control.
