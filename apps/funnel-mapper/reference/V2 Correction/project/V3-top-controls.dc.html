One Plan control. Plan is a scenario switcher and Actual is real data, side by side. This replaces the separate scenario chip, the “vs Baseline” row and the Model/Actual toggle. Baseline is always the reference and says so.
It tells you where you are. When a scenario other than Baseline is active, a slim banner says “Editing Best case. Baseline is untouched” with one click back. Nobody edits a scenario by accident.
Compare is a switch, not a second bar. Turn on Compare with Baseline and blocks and the strip show ▲ ▼ changes. Off by default, so the map stays calm.
A real calendar for numbers. One date control next to the views. In Plan the numbers scale to the length of the range (7 days is a week). In Actual they are the real entries for those dates; days with entries show a dot. Engineering note: the engine already scales Day/Week/Month/Year; confirm how it should scale an arbitrary range.
