## Documented exceptions (each one deliberate)

1. **Touch screens: controls 44 px.** V8 `01_DESIGN_SYSTEM.md §4` requires ≥44 px on touch; the prototype applies it to some controls but not
   to profile tabs, inputs and the focused bar's Back button (32–40 px there). We follow the written V8 rule (accessibility); with a mouse
   every size equals the prototype.
2. **Weather chip says "· Khushab"** and **no weather / snowfall switch** in the profile menu: owner instructions of 14 Nov override the prototype.
3. **"Same as this device" theme option** kept in the profile menu (existing function; owner rule: nothing removed without approval).
4. **Muted text #646965 instead of #6A706B** and two action colours darkened: V8's own accessibility rule (4.5:1); see `packages/ui/tokens.json`.
5. **Icon stroke 1.8**: what the prototype renders (`reuse.js`, `sw=1.8`) and the screenshots show; the asset file declares 1.6.
6. **"Start meeting notes"** is not in search quick actions: the feature does not exist yet (no fake buttons). It arrives with Layer 2 Agents.
7. **Launcher summary line** ("3 things need you today…") still reads "You see the apps that are set up in …": the counts need the
   Office V8 data (P01); shown with real numbers then.
8. **Class-name collisions**: prototype classes that the app uses for other things (`.fbar`, `.shell`, `.main`, `.qa` …) are not taken from later
   layers; V8 values for those components are applied under our own names (for example the focused bar is `.focusbar`).
