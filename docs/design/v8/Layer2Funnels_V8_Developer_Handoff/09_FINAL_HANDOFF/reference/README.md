# Reference specifications (functional detail)

- `PLANNER_PRODUCT_DESIGN_SPEC.md` — Planner product and design spec: **existing behaviour to preserve** (functions, data, rules).
- `EDITORS_DESIGN_BRIEF.md` — every editor feature (Docs, Sheets, Slides, Image, PDF): all features stay.
- `DESIGN_BRIEF_Projects.md` — Projects V2 brief: views, task panel, shortcuts, right-click, states.

These documents are authoritative for **functions**. Their **visual values** (fonts such as Bricolage Grotesque for display, sizes, colours) are **superseded by V8** — use `00_MASTER_DOCUMENTATION/01_DESIGN_SYSTEM.md`.
