Visual A — Complete technical architecture

How to read it: six layers, top to bottom. People, then entry points, then identity and access, then the one database (modules on the left and centre, the workspace wall on the right), then external systems, then build phases with gates G1 and G2. Each colour is the phase in which a part is built or hardened. Each module lists the existing tables it owns. On a phone, scroll sideways.
