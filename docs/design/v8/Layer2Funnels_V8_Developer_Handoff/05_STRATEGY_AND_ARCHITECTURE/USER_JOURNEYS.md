# User journeys

## 1. A client from lead to launch (agency delivery)
```mermaid
journey
  title Client delivery (Layer2Funnels)
  section Win
    Lead added in Clients (Table/Pipeline): 4: Teammate
    Proposal → Active (Lost asks a reason): 4: Teammate
  section Brand Base
    Client fills the Brand Base form (Forms): 3: Client
    Answers appear in Clients › Work › Brand Base: 5: Teammate
  section Strategy
    Client avatar, offers, brand kit, funnel strategy (client-owned copies): 4: Teammate
    Funnel mapped in Funnel Mapper (shared client): 4: Teammate
    Strategy sent for approval → Portal: 4: Client
  section Copy and build
    Copy library versions → Send for approval: 4: Teammate
    Client approves in the Portal: 5: Client
    Project tasks in Projects; build in GHL/ClickFunnels; Build progress in Clients: 4: Team
  section Marketing
    Posts planned and approved in Social Planner, exported to GHL: 3: Team
```

## 2. Owner's day
Launcher → Office Home (My day, Waiting on you, Plans and goals, Projects, Client pipeline, Team today, Organization health) → act in source apps → Planner review → Admin (access review, branding, storage).

## 3. Teammate's day
Launcher → Tasks Today (capture) → Projects My Work → task panel (timer, comments) → Drive editors → notifications.

## 4. Client contact (after G2)
Invitation → Portal Home (journey road, next step) → Requests (answer, upload) → Approvals (approve / ask for changes) → My notes.
